Как проводить

  1. Аудирование: тексты для чтения вслух — в «Режиме учителя» (кнопка в шапке). Читать дважды: первый раз целиком, второй раз — с паузами для ответов. Темп — спокойный, естественный; имена и цифры не выделять голосом. Самостоятельно тексты можно прослушать браузером: кнопка ▶ у каждого текста или «▶ Блок 1 / Блок 2» на панели озвучки; доступны пауза, темп и режим ×2 (текст прозвучит дважды с паузой для ответов — как на экзамене). Голос зависит от браузера; лучше всего — Chrome или Edge.
  2. Монологи: строго по регламенту — 1,5 минуты подготовки (таймер в карточке), не более 2 минут говорения. Оценка — по критериям К1–К3 прямо в карточке; при К1 = 0 весь монолог оценивается в 0 баллов (правило ФИПИ).
  3. Автопроверка: кнопка «Проверить» у каждого задания показывает ✓/✗ и баллы; итоги — в разделе «Результаты». Ответы сохраняются в браузере (localStorage) — можно закрыть и вернуться.
  4. После проверки: оформить «работу над ошибками» по заданиям с наименьшим процентом и добавить в колоду все слова из текстов, которые ученик не знал (правило месяца: каждый текст = +20–30 слов).

  • Задание 3. Типичные ошибки модуля: did + V2 (двойное прошедшее), was/were + V-ing, «braver» в конструкции as … as (ловушка пункта 6), older (не elder для предметов).
